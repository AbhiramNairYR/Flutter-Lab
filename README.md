# Flutter-Lab
### Output of the lab experiments done using flutter
## EX1
### Result:
This experiment demonstrates the development of a basic Flutter application using fundamental widgets and layout components. The application is designed as a student profile/dashboard interface and makes use of widgets such as Container, Row, Column, Expanded, Card, ListTile, and ListView to organize and display information. The experiment also covers creating a Flutter project, checking the Flutter environment and available devices, running the application, and modifying the default main.dart file. Through this experiment, the basic concepts of Flutter UI design, widget hierarchy, and responsive layouts are introduced.

## EX2
### Result:
This experiment demonstrates the development of an adaptive and responsive Flutter user interface that automatically adjusts its layout based on the available screen size. Using the LayoutBuilder widget, the application detects the screen width and displays a Column-based layout for mobile devices and a Row-based layout for tablets and desktops. The experiment introduces responsive design concepts using widgets such as Card, ListTile, Row, Column, and Expanded, and tests the application across different screen sizes to ensure a consistent and user-friendly interface.
### Output:
![EX2 output image](/EX2.png)

## EX3
### Result:
This experiment demonstrates the development of an interactive Flutter student registration form using input fields, form validation, and user actions. The application uses Form, GlobalKey, TextFormField, and ElevatedButton widgets to collect student details such as name, email, and password. Validation is implemented to ensure required information is entered correctly, while the submit button provides feedback using a SnackBar when the form is successfully submitted. The experiment introduces essential concepts of user input, validation, and interactivity in Flutter applications.

![EX3 output image](/EX3.png)

## EX4
### Result:
This experiment demonstrates how to utilize and integrate media assets in a Flutter application by adding and displaying images and videos. The application uses Image.asset() to load an image from the project's assets folder and the video_player package with VideoPlayerController to play and pause a video asset. It also introduces the use of StatefulWidget, initialization, state management, and dispose() for handling video playback and releasing resources properly. Through this experiment, students learn how to configure assets in pubspec.yaml, manage media files, and build an interactive multimedia interface in Flutter.

![EX4 output image](/EX4.png)

## EX5
### Result:
This experiment demonstrates the implementation of navigation and routing in a Flutter application by creating multiple screens such as Home, Profile, and Details. The application uses Navigator.push(), Navigator.pop(), MaterialPageRoute, and named routes to move between different screens and return to previous pages. Through this experiment, students learn how to structure multi-screen Flutter applications, manage screen transitions, and implement both direct and named route navigation for a smooth user experience.

## EX6
### Result:
This experiment demonstrates the implementation of animations and smooth transitions in a Flutter application using the AnimatedContainer widget. The application dynamically changes the size of a widget when the user presses the Animate button, with the transition occurring smoothly over a specified duration. By using StatefulWidget, setState(), and AnimatedContainer, students learn the basics of Flutter's implicit animation system and how to create interactive and visually engaging user interfaces.
